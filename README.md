# Jura Reborn client pack

packwiz metadata for the Jura Reborn server (Prism Launcher auto-update).
Mods are downloaded from their official CurseForge CDN files; no jars are hosted here.

Pre-launch command in Prism:

    "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/godstixx/jura-reborn-pack/main/pack.toml
